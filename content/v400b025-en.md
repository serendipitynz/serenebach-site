Serene Bach v4.0.0-beta.25 has been released.

* Development: Added a CI check that scans dependencies for known vulnerabilities with govulncheck across every released platform.
* Security: Image dimensions are now checked before decoding, so an image whose header declares huge dimensions can no longer exhaust memory (limits: 20000 px per side or 50 million pixels in total).
* Security: Changing a password now signs that user out of every existing session. When you change your own password, your current browser is signed in again with a fresh session.
* Security: Sessions are now stored as hashes rather than the cookie values themselves, so a leaked database or backup cannot be used to sign in. Upgrading signs every user out once.
* Security: AI endpoints configured by non-admin users can no longer reach internal or local network addresses from the server. Admins can still use local LLMs as before.
* Security: Login failures are now recorded in the database, so the brute-force protection on the login page also works when running under CGI.
