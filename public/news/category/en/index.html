Information on 2026-10-17

Serene Bach v4.0.0-beta.23 has been released.

  • Development: Added a build task that updates the version number in one step.
  • Development: Documented the coding style rules in the repository and removed the badge for the now-retired Go Report Card.
  • Fix: Links on the help index opened from the admin "Help" menu no longer lead to 404 pages.
  • Feature: Markdown now supports ruby (furigana and emphasis dots), note paragraphs starting with // , and definition lists.

  • Fix: sbtext line breaks are now emitted as <br />, so they produce well-formed markup in XHTML templates carried over from SB3.
